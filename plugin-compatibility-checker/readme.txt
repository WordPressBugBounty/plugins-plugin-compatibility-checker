### 🆕 WordPress 7.0 Readiness Check

WordPress 7.0 introduces stricter database requirements (**MySQL 8.0+ / MariaDB 10.6+**).  
Many hosting environments still run older database versions, which can silently block updates.

CompatShield now detects:
- Database version compatibility
- Upgrade blockers before they break your site
- Hosting risks that may prevent future updates

Stay ahead of breaking changes before they impact your site.

## ❓ Frequently Asked Questions

= What happens if I don’t activate a license? =  
You must subscribe to the $1/month plan to unlock compatibility results. Without activation, visibility will be limited.

= Why is database compatibility important? =  
Starting with WordPress 7.0, database requirements are stricter (MySQL 8.0+ / MariaDB 10.6+).  
Outdated databases may prevent updates and lead to future security risks.

= Will my site break if database is outdated? =  
Not immediately, but your site may stop receiving WordPress updates, making it vulnerable over time.

= Why does a plugin show “No Data”? =  
This means the plugin is custom, premium, or its version is not available on WordPress.org.

= Do I need to rescan after installing new plugins? =  
Yes, click **Rescan** to include newly added or updated plugins.
